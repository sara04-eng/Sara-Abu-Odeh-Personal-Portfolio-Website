# Sara Abu Odeh — Personal Portfolio Website

A modern, responsive personal portfolio website designed to showcase my professional experience, technical skills, services, academic projects, and full-stack development work.

## 🌐 About the Project

This portfolio website represents my journey as a Software Engineering graduate and Web Developer. It provides an organized and interactive way to explore my background, technical skills, experience, services, and selected projects.

The website features a modern dark technology-focused design with a responsive layout for desktop, tablet, and mobile devices.

## ✨ Features

- Modern dark-themed user interface
- Fully responsive design
- Fixed sidebar navigation
- Smooth section navigation
- Hero / Introduction section
- About Me section
- Experience section
- Technical Skills section
- Services section
- Portfolio / Projects section
- Project category filtering
- Contact section
- CV viewing/download functionality
- Responsive mobile navigation
- Interactive UI elements
- Social and professional links
